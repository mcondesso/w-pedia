# Setup

## Installation

The dependencies of this package are listed under requirements.txt. You can create a virtual environment and install these dependencies with the following commands:

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Environment Variables

Add a .env file to contain the OpenAI Key:

```
OPENAI_API_KEY=<your_openai_api_key>
```
